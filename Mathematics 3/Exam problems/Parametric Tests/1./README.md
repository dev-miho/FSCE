According to existing clinical data, it is considered that the average heart rate in the adult population
is 69 beats per minute with a standard deviation of 4. The data are assumed to be normally distributed.
A medical study has been conducted in order to examine whether the resting pulse rate in a new group
of patients differs from the previously known results.
For that purpose, a random sample of n = 21 patients was taken, and for each patient the heart rate
was measured. The sample data are as follows.

```68, 65, 68, 72, 68, 75, 70, 72, 70, 72, 65, 83, 72, 68, 72, 70, 65, 70, 70, 70, 75```

Using an appropriate test, examine whether there is a statistically significant difference between the
expected average heart rate of this group and the previously known value, at a significance level α = 0.05.
